Для решений использованы обычные массивы: к их элементам удобно обращаться по индексу.
Чтение и вывод вынесены в общий класс ArrayTools, чтобы не повторять одинаковые циклы.

n — длина массива или сторона квадратной матрицы.
Дополнительная память указана без учёта хранения входных данных.

Для задач с массивом сначала вводится n, затем n чисел.
В задачах 2, 3 и 41 после массива вводится x, в задаче 39 — k.
В задаче 48 вводится n, затем n строк по n чисел.
Для задачи 40 входной массив должен быть отсортирован.

## Задача 2. Первое вхождение

Массив просматривается слева направо. При первом совпадении с x возвращается индекс.
Если совпадений нет, возвращается -1.

Время: O(n) в худшем случае, потому что нужно просмотреть весь массив.
Дополнительная память: O(1).

Пример: [7, 2, 7, 2, 9], x = 2 → 1.
Проверяется, что возвращается первое совпадение, а не последнее.
Если искать 8 в [-1, 0, 5], ответ -1.

## Задача 3. Количество вхождений

Счётчик начинается с нуля. Для каждого элемента, равного x, он увеличивается на один.

Время: O(n), один проход по массиву. Дополнительная память: O(1).

Пример: [2, 1, 2, 3, 2], x = 2 → 3.
Также проверено отсутствие совпадений: результат должен быть 0.

## Задача 9. Проверка отсортированности

Сравниваются соседние элементы. Если следующий меньше предыдущего, выводится NO.
Если таких пар нет, выводится YES. Равные соседние числа допустимы.

Время: O(n) в худшем случае. Дополнительная память: O(1).

Пример: [-2, 0, 3, 8] → YES, [7, 7, 7, 7] → YES.
Для [-2, 0, 5, 4] ответ NO: проверяется нарушение порядка в конце.

## Задача 37. Разворот массива

Первый элемент меняется с последним, второй — с предпоследним и так до середины.
Новый массив не создаётся.

Время: O(n), потому что выполняется примерно n/2 обменов. Дополнительная память: O(1).

Пример: массив [1, 2, 3, 4, 5] → [5, 4, 3, 2, 1].
Этот пример проверяет, что средний элемент остаётся на месте.

## Задача 39. Сдвиг вправо

Создаётся новый массив. Каждый элемент записывается на позицию (i + k) % n.
Если k больше длины массива, полные обороты отбрасываются.

Время: O(n), один проход по массиву. Дополнительная память: O(n) для результата.

Пример: [10, 20, 30], k = 7 → [30, 10, 20].
Так проверяется сдвиг, который больше длины массива.

## Задача 40. Удаление дубликатов

Массив должен быть отсортирован. Одинаковые числа стоят рядом.
В начало массива записывается по одному числу из каждой группы повторов.
Выводятся только сохранённые элементы.

Время: O(n), один проход. Дополнительная память: O(1).

Пример: [-2, -2, 0, 3, 3, 3] → [-2, 0, 3].
Пример проверяет несколько групп одинаковых чисел.

## Задача 41. Удаление числа

Все элементы, которые не равны x, записываются в начало массива.
Их порядок сохраняется. В конце выводится только нужная часть массива.

Время: O(n), один проход. Дополнительная память: O(1).

Пример: [2, 1, 2, 3, 2], x = 2 → [1, 3].
Проверяется удаление в начале, середине и конце.
Если в массиве [7, 7, 7] удалить 7, выводится пустая строка.

## Задача 43. Нули в конец

Сначала в начало записываются все ненулевые элементы в исходном порядке.
Оставшаяся часть заполняется нулями.

Время: O(n), два прохода дают не больше 2n шагов. Дополнительная память: O(1).

Пример: [0, 1, 0, -2, 3, 0] → [1, -2, 3, 0, 0, 0].
Проверяется, что порядок ненулевых чисел не меняется.

## Задача 48. Транспонирование матрицы

Элементы matrix[i][j] и matrix[j][i] меняются местами.
Обход идёт только выше главной диагонали, чтобы каждую пару обменять один раз.
Новая матрица не создаётся.

Время: O(n²), выполняется n(n − 1)/2 обменов. Дополнительная память: O(1).

Пример:

```text
До:       После:
1 2       1 3
3 4       2 4
```

Проверяется обмен элементов вне главной диагонали.
